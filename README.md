# کلاس‌میت (ClassMeet) 🎓

سیستم برگزاری **کلاس آنلاین و جلسه تصویری** مشابه Google Meet — کاملاً فارسی، راست‌به‌چپ، با ظاهر گلس‌مورف و پالت رنگی فیروزه‌ای.

> **بدون نیاز به سرور!** سیگنالینگ به‌صورت سرورLESS از طریق رله‌های عمومی انجام می‌شود و صدا/تصویر مستقیماً بین مرورگرها (P2P/WebRTC) رد و بدل می‌شود.

## ✨ امکانات

- **تا ۱۸ نفر همزمان** در هر جلسه (مشابه گوگل میت)
- ویدئو و صدای دوطرفه با WebRTC (رمزگذاری سرتاسری DTLS)
- **اشتراک صفحه** برای ارائه درس
- **چت زنده** گروهی
- **بالا بردن دست** و **واکنش‌های** زنده
- کنترل‌های میزبان: **قطع صدای همه** و **اخراج شرکت‌کننده**
- تشخیص **گوینده فعال** (هایلایت خودکار)
- سنجاق کردن (Pin) شرکت‌کننده یا ارائه‌دهنده
- کد جلسه سه‌بخشی مثل `xxx-xxxx-xxx` و لینک دعوت عمیق
- لیست جلسات اخیر و ذخیره نام (localStorage)
- ریسپانسیو کامل برای **کامپیوتر و اندروید**
- ظرفیت‌سنجی خودکار با پیام «جلسه پر است»

## 🔗 راه‌اندازی روی GitHub Pages (خودکار)

با هر push به شاخه `main`، اکشن GitHub سایت را build و روی GitHub Pages منتشر می‌کند:

- **لینک جلسه:** `https://mhsn-dev.github.io/classmeet/`
- ورک‌فلو: `.github/workflows/deploy.yml`
- ساختن دستی نیز از تب Actions (گزینه `workflow_dispatch`) ممکن است.

## 📱 نحوه استفاده

1. لینک بالا را باز کنید، نام خود را بنویسید و **«جلسه جدید بسازید»** را بزنید.
2. کد جلسه (مثل `a2a-9mrm-z9v`) را با دکمه کپی برای دانشجوها بفرستید.
3. دانشجوها همان لینک را باز می‌کنند یا کد را در صفحه اول وارد می‌کنند.
4. لینک دعوت به‌صورت `.../#/room/کد` است و مستقیم به پیش‌عضویی می‌رسد.

## 🖥 اجرا روی سرور خودتان (VPS کم‌منبع — ۲ گیگ رم / ۱ هسته)

چون همه‌چیز P2P است، سرور فقط فایل‌های استاتیک را می‌دهد؛ یعنی مصرف CPU و RAM تقریباً صفر است:

```bash
git clone https://github.com/mhsn-dev/classmeet.git
cd classmeet
docker compose up -d --build
# سایت روی پورت 8080 بالا می‌آید (یا CLASSMEET_PORT=80 docker compose up -d --build)
```

یا بدون build، ایمیج آماده از GHCR:

```bash
docker run -d -p 8080:8080 --restart unless-stopped ghcr.io/mhsn-dev/classmeet:latest
```

## ⚙️ نکات فنی

| موضوع | جزئیات |
| --- | --- |
| فریم‌ورک | Next.js 16 + TypeScript + Tailwind CSS 4 + shadcn/ui |
| سیگنالینگ | [Trystero](https://trystero.dev) — رله‌های عمومی Nostr (پیش‌فرض) یا MQTT/EMQX |
| رسانه | Mesh WebRTC — صدا/تصویر هرگز از سرور عبور نمی‌کند |
| TURN | رله‌های عمومی openrelay برای عبور از NAT های سخت‌گیر |
| مدیریت حالت | `makeUserState` امضاشده — میکروفون/دوربین/دست/نام هر نفر |
| انتخاب میزبان | earliest join (کمترین `joinedAt`)؛ پس از خروج میزبان، به‌صورت خودکار منتقل می‌شود |
| محدودیت بیت‌ریت | دوربین ۲۶۰k و اشتراک صفحه ۵۰۰k برای شبکه‌های ضعیف |

### تغییر استراتژی سیگنالینگ

در `src/hooks/use-meeting.ts` پارامتر `strategy` تابع `joinRoom` بین `'nostr'` و `'mqtt'` قابل تغییر است. اگر رله‌های Nostr در شبکه شما مسدود بودند، گزینه MQTT (بروکر عمومی EMQX) را انتخاب کنید.

### نکته امنیتی مهم 🔐

اگر از Personal Access Token برای ساخت این ریپو استفاده کرده‌اید و توکن در گفتگو/خروجی دستورها دیده شده، حتماً آن را از `GitHub → Settings → Developer settings → Tokens` **باطل (revoke)** کنید و توکن جدید بسازید.
